# Characters Subsystem Directory
This directory houses character implementations for the Bangladesh Open-World game:
- `characters/player/`: Protagonist character body, modular locomotion, combat, and interaction components.
- `characters/pedestrians/`: Urban crowd agents, tea stall patrons, street hawkers, students.
- `characters/police/`: Dhaka Metropolitan Police (DMP) patrolmen, tactical SWAT, and traffic officers.
- `characters/factions/`: Local neighborhood gangs, riverfront syndicate members, union leaders.

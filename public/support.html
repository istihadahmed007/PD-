SUPPORT & BUG REPORTING

Encountering an issue or graphical glitch in Old Dhaka? Review our troubleshooting steps below or submit a ticket directly to the dev team.

FREQUENT TROUBLESHOOTING

1. Game Crashes Immediately on Launch

Ensure your graphics drivers are up to date and support Vulkan 1.2+. If running on older Intel integrated graphics, install the latest Windows DirectX runtime.

2. Windows Firewall UDP Alert

When joining online multiplayer for the first time, Windows Defender may ask to allow Godot through Private Networks. Click "Allow Access" so UDP port 7777 packets can communicate with the dedicated server.

3. "SmartScreen Protected Your PC" Notice

As this is an indie game build without an expensive EV code-signing certificate, Windows SmartScreen may show an alert. Click "More Info" and select "Run Anyway".

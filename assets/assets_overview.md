# Assets Directory
This directory houses production-ready, original or CC0/licensed 3D models, textures, and materials:
- `assets/models/`: Original Bangladesh 3D meshes (Rickshaws, CNGs, Dhaka architectural props, tea stalls).
- `assets/textures/`: PBR textures for asphalt, brick walls, corrugated tin sheets, concrete.
- `assets/icons/`: Vector and bitmap UI icons for weapons, mini-map blips, phone applications.
